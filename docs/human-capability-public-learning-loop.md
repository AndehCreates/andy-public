# Human capability public learning loop

## Purpose

Andy Public is the public translation and experimentation surface of the Human Capability Ecosystem. It makes improved mental models legible, demonstrates how capability and systems are reasoned about, and creates a disciplined route for public response and comprehension to become upstream learning candidates.

This role is broader than explaining AI safety boundaries. The public body of work should connect knowledge, cognition, exposure, understanding, practice, systems, bounded agent augmentation, action, evidence, reflection, and compounding human leverage. Evidence discipline exists to make ambitious models inspectable and correctable, not to flatten them into generic philosophy.

## Authority boundary

Public translation is a projection, not reference authority. Andy Public may explain, connect, illustrate, and test a public-safe model, but publication does not make that model canonical for the systems it describes.

Three states remain independent:

1. **Reference or evidence state:** what an authoritative source supports, including provenance, uncertainty, and review status.
2. **Internal learning state:** what a responsible system has accepted as a model, decision, practice, or proposal.
3. **Public publication state:** what this repository's schema, public review, sanitization, and build gates allow into generated output.

Movement in one state never silently advances another. A source can be authoritative without being public-safe. A public explanation can be approved without becoming internal truth. A popular explanation can remain wrong.

## Input contract

Inputs to public work must be:

- public-safe, with secrets, personal data, private locations, private hosts, operational details, and unsupported quantitative claims removed;
- source- and provenance-aware, distinguishing direct evidence from theory, synthesis, normative direction, and editorial framing;
- proportional to available evidence, with uncertainty and excluded detail made explicit where material; and
- bounded to the smallest public artifact that can communicate the useful model without exposing an internal control plane.

Public content should use generic responsibility language. Internal names are appropriate in this doctrine only to make routing accountable; they are not an invitation to publish private architecture or operational state.

## What public response means

Public response can include qualitative feedback, comprehension gaps, questions, resonance, contradictions, issue reports, public conversation, content review, and explicitly submitted feedback. Each is a **learning candidate**, not canonical evidence.

Resonance can indicate that a framing is memorable or speaks to a live concern. It cannot by itself establish that a factual claim is true, a theory is sound, an intervention works, or an internal model should change. Silence likewise does not disprove value.

Capture a candidate only with enough context to review it responsibly: the public artifact, the substance of the response, its provenance when voluntarily provided, the concern it raises, and the uncertainty in the interpretation. Do not infer private traits or manufacture a user profile from a public interaction.

## Routing by concern

Route candidates to the system role that can evaluate the underlying concern. Names below identify current internal responsibilities; public content should normally describe the generic role instead.

| Concern in the candidate | Accountable destination | Generic responsibility |
| --- | --- | --- |
| Evidence, source quality, factual contradiction, or model revision | World Knowledge / reference layer | Governed reference knowledge, provenance, and model review |
| Clarity, exposure, orientation, comprehension, or navigation | Flourish / educational layer | Explanation, exposure design, learning paths, and comprehension |
| Practice design, skill transfer, experimentation, or cultivation | Empowering Excellence (EE) / cultivation layer | Deliberate practice, transfer, experiments, and capability cultivation |
| Agent execution, tools, evaluation, or augmentation boundaries | Agent Capability Engine (ACE) | Bounded agent capability, execution, evaluation, and recovery |
| Cross-system coordination, ownership, lifecycle, or routing | Chief | Coordination and accountable handoffs without replacing domain authority |
| Owner intent, values, commitments, or durable personal context | Second Brain | Owner-authored intent and durable context |
| Public wording, structure, discoverability, or explanation quality | Andy Public | Public-safe projection, editorial testing, and publication |

If a candidate spans concerns, split it into bounded proposals or nominate a single coordinating owner while preserving each domain authority. Do not create a new source of truth merely because the public response arrived through Andy Public.

## Bounded learning flow

The learning loop is:

`public artifact -> response or comprehension observation -> provenance-aware candidate -> concern routing -> bounded proposal -> accountable review -> accept, reject, revise, or defer -> separately reviewed public projection`

Learning may flow upstream only through a proposal that names the candidate, the affected model or artifact, the evidence and uncertainty, the accountable destination, and the requested change. The destination applies its own evidence and approval rules. No feedback, issue, conversation, or engagement signal automatically mutates reference knowledge, owner intent, agent policy, practice design, coordination state, or public content.

Andy Public may repair its own explanation through the same bounded process. A clarity change can be editorially valid without claiming that the upstream model changed. Conversely, an upstream model change does not become public until this repository's separate publication gate approves the new projection.

## Evaluation without surveillance expansion

This doctrine does not authorize an analytics backend, tracking expansion, behavioral profiling, or a new data collection system. Testing can use:

- public-safe content review;
- comprehension questions about the relationship a page intended to teach;
- qualitative feedback and public conversation;
- repository issues or similarly explicit public submissions;
- small, consent-aware learning or transfer exercises when participants choose them; and
- review of contradictions, ambiguous wording, and recurring questions.

Prefer the minimum information needed to improve the model or explanation. Record conclusions as bounded observations, not audience-wide claims. Any future proposal for collection infrastructure requires separate scope, privacy, evidence, and publication review.

## Editorial standard

Public work should make a decisive model understandable while showing which parts are observed, theoretical, synthesized, normative, or editorial. It should explain what problem the model addresses, who may benefit, why the framing was chosen, how it can be challenged, what tradeoffs remain, and what would be learned next.

The north-star language of increasing integrated freedom within reality may be used as a public-safe value direction: greater ability to perceive options, understand constraints, choose coherently, and act effectively while remaining accountable to consequences. It must be presented as a normative synthesis, not scientific fact.

Guardrails are enabling constraints. Public safety, provenance, bounded authority, human review, and reversibility should make ambitious synthesis more legible and trustworthy. They should not reduce capability work to avoiding harm or prohibit clear points of view.

## Non-goals

This doctrine does not:

- make Andy Public an internal control plane or canonical knowledge store;
- make engagement, popularity, agreement, or qualitative resonance evidence of truth;
- authorize automatic upstream mutation, autonomous publication, merging, or deployment;
- expose private system topology, implementation detail, source locations, or operational state; or
- claim validated audience comprehension, capability gain, transfer, adoption, or impact without appropriate evidence.
