# World Knowledge evidence inventory

## Public framing

World Knowledge is a governed reference-corpus project that separates source
intake, human review, curated graph records, and bounded read-only retrieval.

## Authoritative sources inspected

- The current registered private source at `main` revision `5c0c02a`, observed
  on 2026-08-12.
- Its current project overview and operating-model documentation.
- A source-owned strict-validation run from an independent clean checkout of

## Verified capabilities

- Markdown-first records use typed frontmatter to distinguish concepts from
  sources and capture relation metadata.
- A human review queue separates candidate material from curated records.
- Retrieval is explicitly bounded and read-only; the corpus is not an
  operational-memory or autonomous-write channel.
- The project includes a local acquisition adapter that keeps newly acquired
  caption material outside the canonical corpus until separate review.

## Verified system decisions

- Source intake, candidate extraction, semantic promotion, and operational
  memory are separate stages.
- Retrieved text is treated as data rather than authority or tool instruction.
- The Markdown corpus remains canonical; a database, global graph interface,
  and bulk external synchronization require a separate demonstrated need.

## Validation evidence

- The reviewed documentation defines non-strict and strict validation for
  frontmatter, relations, links, source status, and placeholder language.
- Strict validation passed for the inspected revision with zero strict warnings.
- This is structural validation only; it does not establish corpus coverage,
  citation completeness, retrieval quality, or research outcomes.

## Human or customer value

The project can support research and system-design work by making the origin,
review state, and retrieval boundary of reference material explicit. This is a
design intent, not evidence of research outcomes or adoption.
