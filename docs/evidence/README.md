# Evidence inventory method

This directory records sanitized, reviewable evidence before any portfolio
project or case-study copy is published. It is not a source-code mirror and it
does not disclose local checkout locations, private hosts, credentials, or
personal data.

Each project inventory records only observed repository identity, stable commit
evidence, public-safe capabilities, decisions, validation, limitations, and
claims that remain unsupported. A pending inventory is not publication approval.

Public material may be created only after the reviewer updates the corresponding
row in `public-review.md` from `pending` to `approved`.

## Required inventory shape

Every inventory uses these headings:

1. Public framing
2. Authoritative sources inspected
3. Verified capabilities
4. Verified system decisions
5. Validation evidence
6. Human or customer value
7. Known limitations
8. Public-safe diagrams and media
9. Claims not currently supported
10. Candidate project and case-study copy
11. Review date and public-review decision
