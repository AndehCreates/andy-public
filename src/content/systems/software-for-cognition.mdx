## How to read this map

This map traces a person’s path back into work after attention changes or an interruption occurs. Useful software captures enough context to make the next action understandable, keeps active work visible without demanding perfect recall, and turns re-entry into a deliberate step. The explanation remains complete without relying on the diagram.

## Map legend

- **Nodes** describe cognitive support responsibilities rather than a prescribed interface.
- **Arrows** show the information a person needs to move between work states.
- **The return path** represents re-entry: continuation, revision, or a deliberate stop can all be valid outcomes.

## What this connects

The connected public work explores local-first workspaces, semantic records, and visible state as supports for continuity. These patterns reduce dependence on fragile working memory, but they do not diagnose attention or replace a person’s judgment about what matters next.
